# SafeSpend

ADHD-friendly money decision planner. Know what you can safely spend before you spend it.

## Open the app

1. Unzip the folder.
2. Double-click `index.html` to open it in Chrome, Edge, Firefox, or Safari.
3. Complete the short setup, or skip bills and funds and add them later.

No install, account, or internet connection is required after the file is on your computer. The app uses a normal browser script (`app.js`) and does not call a server.

Your numbers are stored in this browser only (localStorage). They do not sync to your phone or another computer. Export a backup from Settings. Clearing browser data can erase the plan.

## Safe to Spend

Current balance
− unpaid bills due in the selected window
− future-fund amounts still to set aside
− expected essentials not already spent
− safety buffer
= Safe to Spend

Projected income is shown separately and is not treated as cash on hand. Paying a bill deducts it from the balance and removes it from protected bills, so it is not counted twice.

## Features

- Today dashboard with Today, This week, Until payday, and This month
- Income expected vs received
- Expenses and expected essentials
- Bills, including debt payments, with paid / overdue views
- Future funds with targets and set-asides
- Can I afford this? with a Fits / Pause / Wait recommendation and price comparison
- Impulse pause waiting room
- Money leaks
- Five-minute reset
- Insights from your own entries
- Currency, theme, JSON export / import, example numbers, and full erase
